# 機能設計

## フェーズ

| フェーズ | 内容 |
|---|---|
| Phase 1（初期）| CSVインポートによる取引登録のみ |
| Phase 2（将来）| 取引の手動登録・編集・削除 |

## 画面一覧

| パス | 画面名 | 概要 | フェーズ |
|---|---|---|---|
| `/` | ダッシュボード | 月次サマリー・グラフ | 1 |
| `/transactions` | 取引一覧 | 取引の検索・フィルタ・カテゴリ編集 | 1 |
| `/import` | CSVインポート | 銀行CSVの取り込み | 1 |

## 機能詳細

### 1. CSVインポート

- ドラッグ&ドロップまたはファイル選択
- 口座を選択してインポート（口座に紐づくフォーマット定義を使用）
- 文字コード自動変換（Shift_JIS → UTF-8）
- 重複検出（同一口座・日付・金額・摘要の組み合わせ）
- インポート後、カテゴリを自動分類（後述）

### 2. 取引管理（Phase 1）

- 取引一覧（日付・摘要・金額・カテゴリ・口座）
- フィルタ：期間・カテゴリ・口座・収支種別
- カテゴリの手動編集
- 複数口座の取引を統合表示

### 取引手動登録・編集（Phase 2）

詳細設計は [manual-entry.md](./manual-entry.md) を参照。

- 取引一覧ページのダイアログから新規作成・編集・削除を行う
- CSVインポートと同一の `Transaction` モデルを使用（`import_format_id`をnullableに変更して手動入力を表現）
- `POST /api/transactions`（新規作成）、`PUT /api/transactions/:id`（編集）を追加
- 金額入力は支出/収入トグル＋絶対値入力（内部で符号変換）

### 4. ダッシュボード

- 月次サマリー：収入合計・支出合計・収支差額
- カテゴリ別支出の円グラフ
- 月別推移の棒グラフ（過去12か月）
- 口座ごとのフィルタ切り替え

### 5. 口座管理

- 口座のCRUD
- 口座に銀行フォーマットを紐づける

### 6. カテゴリ管理

- カテゴリのCRUD（カラー・アイコン設定）
- 収支種別（収入 / 支出 / 両方）の設定
- 自動カテゴリルールのCRUD（キーワード・優先度）

### 7. 銀行フォーマット設定

- 銀行ごとのCSVフォーマット定義のCRUD
- 設定項目：銀行名・文字コード・スキップ行数・列インデックス・日付フォーマット

## カテゴリ自動分類

CSVインポート時に以下の優先順位でカテゴリを自動分類する。

```
1. キーワードルール（高速・オフライン）
      ↓ マッチしない場合
2. Claude API（高精度・オンライン必須）
      ↓ APIエラー時
3. 未分類のまま保存（手動設定を促す）
```

### 1. キーワードルール

摘要欄のキーワード部分一致による分類。優先度順に評価し最初にマッチしたカテゴリを適用。

| キーワード | カテゴリ | 優先度 |
|---|---|---|
| 給与 | 給与 | 100 |
| スーパー | 食費 | 50 |
| コンビニ | 食費 | 50 |
| 電気 | 光熱費 | 50 |

### 2. Claude APIによる分類

キーワードルールにマッチしなかった取引の摘要をClaude APIに送信し、カテゴリを推論する。

- モデル：`claude-haiku-4-5`（低コスト・高速）
- インポート単位でまとめてバッチ送信（API呼び出し回数を最小化）
- 同一摘要の分類結果はDBにキャッシュし、重複呼び出しを防ぐ
- 手動で上書きしたカテゴリは再インポート時も保持
